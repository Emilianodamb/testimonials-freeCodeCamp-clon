# Clon de la sección "testimonials" de freeCodeCamp

## El proyecto actual se trata de construir un clon de la sección "testimonials" de freeCodeCamp, el cual se encuentra en la siguiente dirección: https://www.freecodecamp.org/espanol/

El objetivo es replicar la sección de testimonios, incluyendo el diseño, la funcionalidad y la experiencia del usuario. Sin recurrir al uso de IA generativa, haciendo uso de React con fines educativos y de aprendizaje. El proyecto se centrará en la implementación de componentes reutilizables, manejo de estado, y la integración de estilos para lograr una apariencia similar a la sección original.


## Descomposición del problema en partes:

1. Analizar el sitio. Identificar componentes, estructura y estilos. [ * ]

- Section: "Testimonials"
- ItemList: Lista de elementos "Items" 
- Item: Componente individual: 
-- "Título: {Nombre} en {País}"
-- "Rol: {Puesto} en {Empresa}"
-- "Testimonio: {texto}"
-- "Imagen de perfil"

2. Replicar la estructura en nuestro proyecto. [  ]
3. Crear fuente de orígen de los datos. [ * ]
